
## test

Сервис предполагает использование в качестве ресурса, где можно смотреть с помощью ручек котировки валютных пар - поиск пары по айди или просмотр последнего обновления по паре через параметр запроса. Пользователь создает интересующую его пару и после этого с помощью внешнего API сервис в фоне обновляет котировку

## Стек: 

go 1.25

pgxpool

gin

postgres

docker

## Локально нужно иметь

docker

git

postman 

## План действий
1. Открыть docker desktop
2. В терминале вставить "git clone https://github.com/smartWalrus/test.git" для клонирования кода с репозитория на локальную машину
3. Перейти в директорию "cd test"
4. Запустить код в контейнерах с помощью "docker-compose up --build"
5. Проверить с помощью команды в терминале "docker ps" что запустилось 2 контейнера с кодом и Postgres.
6. Открыть постман
7. Сначала необходимо создать пару для Парсинга через метод POST с помощью url "http://localhost:8080/api/quotes"
8. Далее в теле запроса пишем {"pair": "EURUSD"}. *варианты на выбор (EURUSD, EURMXN, EURRUB)
9. Получаем айди созданной пары
10. После создания, чтобы получить актуальный курс валютной пары через метод GET пишем "http://localhost:8080/api/quotes/1*" *или любой другой айди
11. Также можно посмотреть последнюю цену через запрос "http://localhost:8080/api/quotes/latest?pair=EURUSD" *или любая другая пара, существующая в таблице
12. После проверки интересующих функций завершить программу с последующим ее удалением можно с помощью команды в терминале - "docker-compose down -v"

## Как все это работает? 

1. Пользователь отправляет POST-запрос с валютной парой.
2. Сервис создаёт запись в БД со статусом pending и возвращает ID.
3. Во время запроса пользователя запускается функция, которая запрашивает курс у внешнего API.
4. Цена обновляется в БД, статус меняется на completed.
5. Пользователь получает котировку по ID или через latest.
